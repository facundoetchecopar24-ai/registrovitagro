Tarifas y calculos
Redondeo de horarios: Si la entrada/salida real difiere del horario oficial del turno en ≤ este margen, se ajusta automáticamente al horario oficial. Si la diferencia es mayor, se toma la hora real (llegada tarde / salida anticipada). Si el empleado entró dentro del margen y las horas resultantes son menores a las horas base, se garantizan las horas base completas. Máximo recomendado: 20 min.
Empleados sin descuento de franquicia
A estos empleados no se les descuenta la franquicia de descanso cuando no registran marcaciones de descanso en el reloj. Útil para empleados que salen antes compensando el descanso con horario reducido.
Importante: si el empleado sí registra descanso en el reloj, el sistema siempre lo calcula normalmente.
